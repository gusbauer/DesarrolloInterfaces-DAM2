# Preguntas rápidas de examen

**¿Qué es Angular?** Framework frontend.

**¿Qué es TypeScript?** Lenguaje utilizado principalmente con Angular.

**¿Qué es un componente?** Unidad de UI formada normalmente por TS, HTML y CSS.

**¿Qué es standalone?** Componente que declara directamente sus dependencias sin depender obligatoriamente de NgModule.

**¿Qué es una interface?** Define la estructura/tipo de un objeto.

**¿Qué es `Alumno[]`?** Array de alumnos.

**¿Qué es `this`?** Referencia a la instancia actual.

**¿Qué hace un servicio?** Encapsula lógica reutilizable; aquí centraliza HTTP.

**¿Qué es DI?** Mecanismo por el que Angular proporciona dependencias.

**¿Qué hace `HttpClient`?** Peticiones HTTP.

**¿Qué es un Observable?** Flujo asíncrono de datos.

**¿Qué hace `subscribe()`?** Se suscribe a las emisiones y errores.

**¿Qué hace `next`?** Gestiona un valor recibido correctamente.

**Constructor vs `ngOnInit`?** Constructor crea/inyecta; `ngOnInit` inicializa lógica de ciclo de vida.

**¿Qué es CRUD?** Create, Read, Update, Delete.

**¿Endpoint?** Ruta concreta de una API.

**¿JSON?** Formato de intercambio de datos.

**¿JSON Server?** API REST simulada a partir de JSON.

**¿`router-outlet`?** Lugar donde Router renderiza el componente activo.

**¿Signal y Observable son lo mismo?** No.

**¿`npx` instala Node?** No.

**¿GET crea?** No, normalmente lee.

**¿Una interface crea objetos?** No.
