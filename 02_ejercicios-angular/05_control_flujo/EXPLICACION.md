# Control de flujo

- `@if`: muestra un bloque si se cumple una condición.
- `@else`: alternativa.
- `@for`: recorre una colección.
- `alumno`: variable temporal de cada vuelta.
- `track alumno.id`: ayuda a identificar de forma estable cada elemento.

Esto produce **renderizado dinámico**: el número de elementos depende de los datos.
