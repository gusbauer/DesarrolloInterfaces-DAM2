# Interface `Alumno`

- `export`: permite importar la interface.
- `interface`: define la estructura/tipo esperado.
- `id: number`: identificador numérico.
- `nombre`, `apellidos`, `email`, `fechaNacimiento`: propiedades de tipo `string`.

Una interface **no crea objetos**. Define cómo deben ser.

`Alumno[]` significa: array cuyos elementos son del tipo `Alumno`.
