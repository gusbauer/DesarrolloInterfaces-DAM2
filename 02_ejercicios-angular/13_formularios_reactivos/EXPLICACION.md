# Reactive Forms

- `FormGroup`: formulario completo.
- `FormControl`: campo individual.
- `Validators.required`: obligatorio.
- `Validators.email`: formato email.
- `[formGroup]`: conecta HTML con el grupo.
- `formControlName`: conecta cada input con su control.
- `(ngSubmit)`: evento de envío.
- `invalid`: indica formulario no válido.
- `touched`: el usuario ya ha interactuado con el campo.
