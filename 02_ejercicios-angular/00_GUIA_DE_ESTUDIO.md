# Guía de estudio

Para cada fragmento intenta responder:

- ¿Qué pieza de Angular es?
- ¿Qué archivo se está tocando?
- ¿Qué hace en palabras normales?
- ¿Cómo lo explicarías técnicamente?
- ¿Qué pasaría si falta?
- ¿Qué error típico podría aparecer?

## Vocabulario clave

Angular, TypeScript, componente, template, standalone component, modelo, interface, objeto, propiedad, método, `this`, servicio, inyección de dependencias, `HttpClient`, `Observable`, `subscribe`, `next`, `error`, CRUD, endpoint, JSON, API REST, routing, `router-outlet`, Reactive Forms, Signals y RxJS.
