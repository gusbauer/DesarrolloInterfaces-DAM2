# Listado local

## TypeScript

- Se importa `Component` y el tipo `Alumno`.
- La clase `Alumnos` guarda `alumnos: Alumno[]`.
- Cada elemento del array es un objeto alumno.

## HTML

- `table`: tabla.
- `thead`: cabecera.
- `tbody`: cuerpo.
- `@for`: una fila por alumno.
- `{{ alumno.nombre }}`: interpolación.

**¿Por qué se usa el punto?** Porque `alumno` es un objeto y `nombre` una propiedad.
