# Fuentes y alcance

Este material organiza y explica:

- el tutorial Angular 20+ aportado para la asignatura;
- los apuntes de clase compartidos sobre `gestion-alumnos`;
- componentes, interfaces, listados, servicios, HttpClient, Observable, CRUD, routing, formularios y JSON Server;
- el ejercicio de CRUD de productos.

No se incluye el proyecto original completo del profesor: este repositorio contiene ejemplos y explicaciones educativas preparados para estudiar.
